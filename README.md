# 📈 Stock Market Price Prediction Dashboard

A Machine Learning-based web application built using Streamlit that predicts stock prices and visualizes market trends using a TradingView-style dashboard.

---

## 🚀 Features

- 📊 Real-time stock data using Yahoo Finance  
- 🕯️ TradingView-style candlestick chart  
- 📈 Moving Averages (MA20, MA50)  
- 🤖 Machine Learning prediction (Linear Regression)  
- 🔮 Future price prediction (30 days)  
- 💱 USD to INR conversion  
- 📥 Download stock data  

---

## 🧠 Technologies Used

- Python  
- Streamlit  
- Pandas & NumPy  
- Scikit-learn  
- Plotly  
- Yahoo Finance API
